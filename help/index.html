RuliManager 설명서

v0.83 기준 · 그림은 실제 화면을 단순하게 그린 것이라 세부 모양은 다를 수 있습니다 · 어느 화면에서든 F1 을 누르면 그 화면의 장이 열립니다.

시작하기

RuliManager 는 PC 에 있는 영상 파일을 배우 · 제작사 · 태그 · 컬렉션으로 정리해서 보는 프로그램입니다. 영상 파일은 그대로 두고, 정보(제목 · 배우 · 별점 등)는 프로그램 DB 에 따로 저장합니다.

처음 쓸 때

  1. 위쪽 [폴더 관리] 에서 영상이 들어 있는 폴더를 추가합니다. 하위 폴더까지 모두 찾습니다 (mp4 · mkv · avi · wmv · mov · webm · ts 등). USB 메모리 · 외장 하드에 있는 폴더는 물어볼 때 [예] 를 고르면 이동식 디스크로 등록됩니다.
  2. 새로 찾은 영상은 카드에 ● 임시 로 표시됩니다. 영상을 고르고 정보를 고친 뒤 [저장] 하거나 다른 영상을 고르면 정식으로 등록됩니다.
  3. 영상 폴더에 같은 이름의 이미지(ABC-123.jpg 등)가 있으면 카드 이미지로, 텍스트 파일(ABC-123.txt)이 있으면 영상 정보로 자동으로 읽습니다.
  4. 폴더 구조로 배우 · 제작사를 알아냅니다: 폴더\배우\영상\영상.mp4 → 배우, 폴더\제작사\배우\영상\영상.mp4 → 제작사 · 배우.
  5. 파일 이름에서 품번(예: ABC-123)을 읽고, 품번 관리에 등록된 접두어면 제작사 · 레이블도 자동으로 정해집니다.

정보 저장과 DB 반영

프로그램을 쓰는 동안 바꾼 정보는 작업용 사본에 저장되고, 아래쪽 초록색 [DB 반영] 을 누르거나 프로그램을 닫을 때 원본 DB 에 반영됩니다. 반영할 내용이 있을 때만 [DB 반영] 이 켜집니다. 자세한 내용은 데이터와 백업을 보세요.

팁 어느 화면에서든 F1 을 누르면 그 화면의 설명이 열립니다.

화면 구성

  1. 폴더 · 새로고침 - [폴더 관리] 로 등록 폴더 추가 · 제거, [새로고침] F5 은 새 파일 찾기, [재 스캔] 은 저장된 영상에도 폴더 구조를 다시 적용해 빈 배우 · 제작사 · 발매일을 채웁니다.
  2. [목록 관리 ▾] · 검색 - 배우 / 제작사 / 태그 / 품번 / 파일 관리 창을 엽니다. 검색 칸은 이름 · 품번 · 제목 · 배우 · 제작사 · 태그를 바로 찾습니다 (띄어 쓰면 모두 포함하는 것만).
  3. 설정 (톱니바퀴) - 설정 창. 미리보기를 만드는 동안에는 톱니바퀴가 돌고, 오른쪽 클릭으로 만들기를 멈출 수 있습니다.
  4. 탭 - 영상 · 배우 · 제작사 · 태그 · 컬렉션.
  5. 도구줄 - 정렬 · 방향, 보기 방식, 확대 슬라이더, 장르 칩, 페이지 단추. 카드와 함께 스크롤됩니다.
  6. 카드 격자 - 고르면 오른쪽에 상세 정보, 더블클릭 · Enter · Space 는 재생(영상) 또는 들어가기(배우 · 제작사 · 태그 · 컬렉션).
  7. 상세 화면 - 고른 항목의 정보. 영상 상세 참고. 격자와 사이의 얇은 바를 누르면 접고 펼 수 있고, 설정에서 왼쪽 / 오른쪽 위치를 바꿀 수 있습니다.
  8. 아래 단추 - 재생, DB 에서 삭제 (파일은 지우지 않음), 탐색기에서 보기, DB 폴더 열기, DB 반영, 정보 txt 생성.

영상 카드

  1. 체크 칸 - 마우스를 올리면 나타남. 여러 영상을 체크해서 한 번에 삭제 · 미리보기 만들기 등을 합니다.
  2. 별점 리본 - 별점이 있는 영상만.
  3. 재생 시간
  4. 제목 (최대 3줄)
  5. 품번
  6. 해상도 · 등급 표시 (예: 1080p | FHD)
  7. 배우 수 · 태그 수 · 물방울 - 숫자에 마우스를 올려 두면 출연 배우 카드 / 태그 칩이 팝업으로 나옵니다.

영상 탭

등록된 모든 영상을 카드로 봅니다. 위 도구줄에서 정렬(이름 · 제목 · 크기 · 수정일 · 별점 · 발매일 · 배우 · 제작사 · 품번 · 재생 시간 · 해상도 등)과 방향 [▲▼] 을 고릅니다.

보기 방식

  • 격자 - 기본 카드. 카드 이미지에 마우스를 올리면 미리보기 영상(만들어 둔 경우)이 그 자리에서 재생됩니다.
  • 리스트 - 표 형태. 열 머리글을 누르면 정렬됩니다.
  • 패키지 - 세로 커버만 촘촘히. 마우스를 올려 두면 격자 카드가 팝업으로 나옵니다.
  • 월 모드 - 화면에 보이는 칸이 모두 동시에 미리보기를 재생합니다. 프로그램이 뒤로 가거나 최소화되면 멈춥니다.

그 밖의 도구

  • 확대 슬라이더 - 카드 크기. 끌기 · 클릭 · 휠 · ← → 로 바꾸고 탭마다 따로 기억합니다.
  • 장르(태그) 칩 - 칩을 누르면 그 태그가 있는 영상만. [장르숨김] 은 칩 줄을 숨깁니다.
  • 페이지 - 한 페이지 개수(전체 / 50 / 100 / 250 / 500 / 1000)는 탭마다 따로 저장됩니다.
  • [가로 | 세로] - 카드 이미지 방향.
  • 오른쪽 클릭 메뉴 - 재생, 이 영상 새로고침, 탐색기에서 보기, 텍스트로 정보 입력, 웹페이지 내용 붙여넣기, 스크린샷 추출, 미리보기 만들기, 컬렉션에 추가, DB 에서 삭제.

분할 영상

ABC-123_1.mp4, ABC-123_2.mp4 처럼 이름 끝의 _숫자 만 다른 파일은 한 작품의 파트로 봅니다. 설정에서 분할 영상 합쳐서 보기 를 켜면 첫 파트 카드 하나만 보이고, 카드 이미지를 파트 수만큼 나눠서 원하는 파트를 고르고 재생합니다.

주의 연결되지 않은 이동식 디스크의 영상은 보기 전용입니다. 재생 · 수정은 디스크를 연결한 뒤에 할 수 있습니다.

영상 상세

고친 내용은 [저장] 을 누르거나 다른 영상을 고를 때 저장됩니다. 별점과 물방울은 누르는 즉시 저장됩니다.

  • 이미지 - [이미지 변경] 으로 파일을 고르거나 탐색기에서 이미지를 끌어다 놓습니다. [이미지 검색] 은 품번으로 인터넷 이미지를 찾습니다. 더블클릭하면 원본 크기로 봅니다.
  • 발매일 - 19980217 처럼 숫자만 쳐도 됩니다. 오른쪽 콤보는 검열 정보입니다.
  • 배우 · 태그 칩 - 글자를 치면 자동 완성 목록이 나옵니다. 칩의 × 로 빼고, ⌄ 로 목록 창에서 고릅니다. 목록에 없는 이름은 새로 추가됩니다.
  • 제작사 · 레이블 카드 - 품번으로 자동으로 정해지고, 더블클릭하면 다른 제작사로 바꿉니다.
  • 시리즈 - 작품의 시리즈 이름을 자유롭게 적습니다 (검색에 포함).
  • 스크린샷 - 오른쪽 클릭 [스크린샷 추출] 로 만든 장면 이미지가 태그 아래에 나옵니다.

정보 입력 (txt · 붙여넣기)

영상 정보를 하나하나 치지 않고 한 번에 채우는 방법이 세 가지 있습니다.

웹페이지 내용 붙여넣기

작품 사이트 화면을 드래그해서 복사한 뒤, 영상 오른쪽 클릭 [웹페이지 내용 붙여넣기...] 창에 붙여넣으면 품번 · 제목 · 발매일 · 배우 · 제작사 · 레이블 · 태그를 찾아 채웁니다. 처음 보는 태그나 제작사가 있으면 기존 항목에 연결할지, 새로 추가할지 묻습니다. [공백라인 제거] 로 빈 줄을 정리할 수 있습니다.

텍스트로 정보 입력

오른쪽 클릭 [텍스트로 정보 입력...] 은 지금 정보를 항목: 값 형식으로 보여 주는 창입니다. 고쳐서 [적용] 하면 반영됩니다.

제목: 영상 제목
발매일: 2024-05-17
배우: 배우 A, 배우 B
제작사: 제작사 이름
태그: 드라마, 코미디
별점: 3.5

영상 폴더의 txt

같은 형식의 txt 를 영상 옆에 두면 새로 찾을 때 자동으로 읽습니다. 반대로 아래 [정보 txt 생성] 은 저장된 정보를 영상마다 txt 로 써 줍니다 (배우 폴더에는 배우 정보 txt).

팁 .txt 파일을 영상 카드나 리스트 줄에 끌어다 놓으면 웹페이지 붙여넣기와 같이 처리됩니다.

미리보기 영상

카드에 마우스를 올렸을 때 재생되는 짧은 미리보기 영상을 만듭니다. ffmpeg.exe 가 필요합니다 (프로그램 폴더, 프로그램 폴더\ffmpeg\bin, 또는 PATH 에 두면 됩니다).

  • 하나 만들기 - 영상 오른쪽 클릭 [미리보기 만들기]. 이미 있으면 [미리보기 다시 만들기] 로 나옵니다.
  • 분할 영상 - 한 파트에서 만들면 같은 묶음의 모든 파트를 한 번에 만듭니다. 이미 있는 파트는 건너뛰고, 모든 파트에 있으면 모두 다시 만듭니다.
  • 체크한 영상 - 카드를 체크한 뒤 오른쪽 클릭 [미리보기 만들기(n)].
  • 모두 - 설정 [DB 관리] 의 [일괄 만들기](없는 것만) · [재생성](모두 다시) · [모두 삭제].
  • 중단 - 만드는 동안 톱니바퀴가 돕니다. 톱니바퀴 오른쪽 클릭 또는 설정의 [만들기 중단].

만드는 진행은 아래 상태 줄에 표시되고, 다른 작업을 하는 동안 뒤에서 한 편씩 만듭니다.

배우 탭

  • [격자 | 트리맵] - 트리맵은 배우를 출연 수(기준 콤보로 바꿈)만큼의 칸 크기로 보여 줍니다.
  • 성별 거르기 - [선택없음 | 여성만 | 남성만].
  • 정렬 - [이름 | 작품수]. 즐겨찾기(♥)한 배우가 항상 먼저 나옵니다. ♥ 는 카드 오른쪽 위에 마우스를 올리고 누릅니다.
  • 오른쪽 상세 - 사진 · 이름 · 별점 · 나이 · 국적 · 신체 · 데뷔 · 링크. 별점은 바로 누를 수 있습니다.
  • 오른쪽 클릭 - 편집 F2, 텍스트로 정보 입력, 다른 배우와 합치기, 삭제 Del.
  • 빈 곳 오른쪽 클릭 → [새 배우 추가...].

배우 출연작 화면

배우 카드를 더블클릭하면 위에 배우 사진 · 정보, 아래에 출연 영상이 나옵니다. [◀ 배우 목록] 이나 Backspace 로 돌아갑니다.

  • [격자 | 연도별] - 연도별은 가로 1~12월 × 세로 연도로 출연작을 발매일에 맞춰 늘어놓습니다.
  • 출연작 화면의 정렬 · 별점 거르기 · 페이지 개수는 영상 탭과 따로 저장됩니다.

제작사 탭

제작사를 카드로 봅니다. 제작사는 상위 · 하위(예: 그룹 › 회사 › 브랜드)로 묶을 수 있고, 카드 배경색이 레벨을 나타냅니다. 보기 방식은 [격자 | 리스트 | 계층] 세 가지입니다.

  • 격자 - 정렬([이름 | 영상수])과 검색 순서대로.
  • 리스트 - 이름 · 영상 수 표. 열 머리글로 정렬.
  • 계층 - 상위 → 하위 트리. − / + 로 접고 펼칩니다.
  • 빈 곳 오른쪽 클릭 → [새 제작사 추가...], 카드 오른쪽 클릭 → 편집 · 삭제.

제작사 영상 화면

제작사 카드를 더블클릭하면 그 제작사의 영상이 나옵니다. 위쪽에는 로고 · 메모 · 링크와 함께 직속 상위(▲) · 하위(└) 제작사 칸이 있고, 더블클릭하면 그 제작사로 이동합니다.

[레이블] 보기는 영상을 레이블(품번 접두어) 묶음으로 나눠 보여 줍니다. 묶음 머리줄을 오른쪽 클릭하면 품번 관리에서 보기 · 등록할 수 있습니다.

태그 탭

  • 정렬 - 위쪽 콤보 [이름 | 영상수] 와 [▲▼]. 바꾸면 맨 위부터 다시 보입니다.
  • 즐겨찾기 - 카드 오른쪽 위 하트. 즐겨찾기한 태그가 먼저 나옵니다.
  • 병합 - 카드 오른쪽 클릭 [다른 태그와 병합...] → 영상의 태그가 고른 태그로 바뀌고 원래 태그는 지워집니다.
  • 여러 개 삭제 - 카드를 체크한 뒤 Del.
  • 카드를 더블클릭하면 그 태그가 붙은 영상 화면(오른쪽에 영상 상세)으로 들어갑니다.
  • 카드 이름은 "한글 이름 (영어, 일본어)" 로 표시됩니다 - 태그 관리에서 입력.

컬렉션 탭

직접 고른 영상 묶음입니다. 빈 곳 오른쪽 클릭 [새 컬렉션 추가...] 로 만들고, 영상 오른쪽 클릭 [컬렉션에 추가 ▸] 로 넣고 뺍니다. 컬렉션마다 제목 · 커버 이미지 · 메모를 가지며, 카드를 더블클릭하면 위 그림처럼 들어갑니다.

품번 관리

[목록 관리 ▾] → [품번 관리...]. 품번 접두어마다 제작사와 레이블을 정해 두면, 영상의 품번만으로 제작사 · 레이블이 자동으로 정해집니다.

  • 싱글 - 접두어 하나에 레이블 하나 (예: ABC → 레이블 1).
  • 복합 - 같은 접두어를 뒷번호로 나눠 여러 레이블로. 레이블명을 고르고 [추가] · [삭제] · [▲▼] 로 순서를 정한 뒤, 뒷번호 칸에 그 레이블의 번호를 한 줄에 하나씩 적습니다. 표에는 "(*복합)" 으로 표시됩니다.
  • 같은 접두어를 여러 제작사가 쓰면 영상의 제작사를 보고 고릅니다. 고를 수 없으면 "(품번 중복 · 제작사 필요)" 로 표시됩니다.
  • [웹페이지 붙여넣기...] - 사이트의 레이블 목록을 붙여넣어 한 번에 등록합니다.
  • 레이블명에 다른 이름을 적어 두면 붙여넣기에서 다른 표기도 같은 레이블로 알아봅니다.

배우 관리

[목록 관리 ▾] → [배우 관리...] 또는 배우 카드 F2. 왼쪽 표에서 배우를 고르고 오른쪽에서 사진 · 이름 · 성별 · 생년월일 · 국적 · 키 · 치수 · 데뷔 · 은퇴 · 별점 · 링크 · 메모를 고친 뒤 [저장] 합니다.

  • 이름 콤보 - 대표 이름과 별칭이 함께 들어 있습니다. 새 이름은 입력 후 Enter, 마지막으로 고른 이름이 대표 이름입니다.
  • "한글 이름(English, 日本語)" 처럼 적으면 언어별 이름으로 나눠서 비교합니다 (붙여넣기 · txt 에서 다른 언어로 적혀도 같은 배우).
  • 열 머리글을 누르면 그 열로 정렬합니다.

제작사 관리

[목록 관리 ▾] → [제작사 관리...]. 왼쪽 트리에서 제작사를 고르고 이름 · 서브이름 · 이미지(SVG 도 됨) · 상위 제작사 · 하위 제작사 · 링크 · 메모를 정합니다. 트리에서 끌어서 다른 제작사 아래로 옮기면 상위 제작사가 바뀝니다.

태그 관리

[목록 관리 ▾] → [태그 관리...]. 이름 · 다른 이름(줄마다) · 영어 · 일본어 이름을 정합니다. 다른 이름이나 영어 · 일본어로 적힌 태그도 붙여넣기 · txt 에서 이 태그로 바뀝니다. [일괄 등록] 으로 여러 태그를 한 번에 추가할 수 있습니다 (한 줄에 하나 또는 쉼표).

파일 관리

[목록 관리 ▾] → [파일 관리...]. 등록 폴더의 실제 폴더 · 파일을 트리로 보여 주고, DB 정보와 폴더 구조(제작사 \ 배우 \ 영상)가 맞지 않는 영상을 찾아 고칩니다. 항목을 오른쪽 클릭하면 폴더 열기 등의 메뉴가 나옵니다.

주의 파일 · 폴더 이름을 실제로 바꾸는 기능입니다. 고치기 전에 목록을 잘 확인하세요.

설정

오른쪽 위 톱니바퀴. 탭 네 개로 나뉩니다.

  • 표시 - 카드에 해상도 · 재생 시간 표시, SFW(배우 · 영상 이미지를 모자이크로), 분할 영상 합쳐서 보기, 별점 단위(1점 / 0.5점).
  • 상세 화면 - 상세 화면 위치(왼쪽 / 오른쪽), 스크린샷 가로 배치 수.
  • 테마 - 색상표(Stash · Dark · Midnight). 미리보기로 확인하고, 다시 시작하면 적용됩니다.
  • DB 관리 - DB 삭제(영상 / 배우 / 제작사 / 태그), 텍스트 내보내기 · 일괄 등록, 미리보기 영상 일괄 만들기 · 재생성 · 모두 삭제.

데이터와 백업

  • DB 는 실행 파일 폴더의 library.vmdb(정보)와 images.vmdb(배우 사진 · 제작사 이미지) 두 파일입니다. 두 파일만 옮기면 다른 PC 에서도 그대로 쓸 수 있습니다. 아래 [DB 폴더 열기] 로 폴더를 엽니다.
  • 실행 중에는 작업용 사본에 저장하고, [DB 반영] 이나 종료할 때 원본에 반영합니다.
  • 프로그램을 켤 때마다 DB 폴더의 backup 에 자동 백업합니다 (파일마다 최근 10개). 되돌리려면 프로그램을 끄고 백업 파일을 원래 이름으로 바꿔 덮어씁니다.
  • 프로그램 버전이 바뀌어 DB 형식을 고칠 때는 DbBackup 폴더에 원본을 먼저 백업합니다.
  • 이동식 디스크 영상의 커버는 캐시에 보관해서 디스크를 빼도 카드 이미지가 보입니다.
