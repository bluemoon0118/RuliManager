# RuliManager v0.1 (MFC, Visual Studio 2022)

- 버전: 0.1 — 창 제목 "RuliManager v0.1", 파일 버전 정보 0.1 (`RuliManager.rc` 의 CAPTION 과 VERSIONINFO 에서 변경)

## 빌드
1. Visual Studio Installer에서 **"C++를 사용한 데스크톱 개발"** + **"최신 v143 빌드 도구용 C++ MFC"** 구성 요소 설치
2. `RuliManager.sln` 열기 → 구성 `Debug|x64` 또는 `Release|x64` → 빌드(Ctrl+Shift+B) → 실행(F5) — 실행 파일 이름은 `RuliManager.exe` (폴더 `D:\Project\RuliManager`, 예전 이름 VideoManager 에서 바꿈. 기존 데이터를 그대로 쓰도록 내부 저장 이름 — 설정 레지스트리 키 · %APPDATA%/%LOCALAPPDATA% 폴더 · DB 암호화 키 — 는 VideoManager 그대로)

## 기능
- **폴더 추가/제거/새로고침**: 하위 폴더까지 동영상 검색 (mp4, mkv, avi, wmv, mov, webm, ts 등). 새로 찾은 파일은 **임시 목록**(`pending.tsv`)에 기록되고 격자에 "● 임시"로 표시 → 영상 정보를 저장([저장] 또는 정보 수정 후 다른 영상 선택)하면 정식 DB(`library.tsv`)에 등록
  - **영상 폴더 텍스트 → 영상 정보**: 스캔 · 새로고침으로 새 영상을 찾을 때(임시 항목), [재 스캔] 때는 저장된 영상도, 영상 폴더의 txt(상위 폴더 이름 기준 `ABC-123\ABC-123.txt` → 폴더 이름의 '_' 왼쪽이 같은 txt → 같은 이름 `ABC-123.txt` / `ABC-123.mp4.txt` → '_' 왼쪽이 같은 이름 → 폴더에 영상과 txt 가 하나씩이면 그 파일, 배우 정보 파일 제외)에서 `항목: 값` 을 읽어 비어 있는 칸만 채운 뒤 남은 빈칸은 폴더 구조로. 인식 항목: 제목/title/タイトル, 발매일/출시일/release/発売日/配信開始日, 별점/rating(숫자 또는 ★), 배우/출연/cast/出演者/女優(여러 명 → 별칭이면 배우 이름 + 참여 별칭으로, `한글이름, (English Name, なまえ)` 처럼 괄호 앞에 쉼표가 있어도 한 사람으로 읽음. 등록 배우 이름 · 별칭과 언어 단위(한글 / 영어 / 일어 — 괄호 앞 이름, 괄호 안 각 이름)로 같은 언어끼리 비교해서 한 언어라도 같으면 다른 언어 이름은 보지 않고 그 배우로 연결 — 공백 · 대소문자 무시, 영어는 단어 순서도 무시(Hikaru Nagi = Nagi Hikaru), 여러 배우가 걸리면 한글 → 일어 → 영어 순으로 맞은 배우, 같은 배우로 연결된 이름이 여러 개면 하나로). 이 언어 단위 비교는 폴더 구조로 정하는 배우(폴더 이름 `나기 히카루` → 배우 `나기 히카루(Hikaru Nagi, 凪ひかる)`), 영상 배우 칸 정리, 새 배우 추가 판단에도 똑같이 적용. 시작 · 스캔 때 사진 · 정보 · 별칭 · 별점 · 즐겨찾기가 하나도 없는 배우가 다른 배우와 언어 단위 이름이 같으면 그 배우로 합침(영상의 배우 표기도 바꿈). 별칭도 언어 단위로 비교 — 배우 관리 창 저장 · 배우 폴더 txt 의 다른 이름 추가 때 대표 이름이나 이미 있는 별칭과 한글 / 영어 / 일어 이름 중 하나라도 같으면 넣지 않음(예: `나기 히카루(Hikaru Nagi, 凪ひかる)` 의 별칭 `나기 히카루(凪ひかる)` 는 무시). 시작 · 스캔 때 이미 들어가 있는 그런 별칭도 빼고 영상의 참여 별칭에서도 정리, 스튜디오/제작사/메이커/maker/label/メーカー, 태그/장르/genre/ジャンル, 물방울. 메모/설명/줄거리/plot/内容 항목은 무시(영상 메모 기능 삭제). 목록은 쉼표 · 、 · / · | · # 로 구분(태그는 / 로 나누지 않음 — "OL/사무원" 같은 태그 그대로). 스튜디오 · 태그가 목록에 이미 있으면 목록의 표기(대소문자)로 맞추고, 없으면 스튜디오 / 태그 목록에 새로 추가. [정보 txt 생성]으로 만든 영상 txt 도 그대로 다시 읽힘
- **[정보 txt 생성]** (하단, [DB 반영] 오른쪽): 확인 후 저장된 영상마다 같은 폴더에 `영상이름.txt`(파일 · 제목 · 발매일 · 별점 · 배우 · 참여 별칭 · 스튜디오 · 태그 · 물방울), 배우 폴더가 있는 배우마다 배우 폴더에 `배우폴더이름.txt`(이름 · 다른이름 #… · 성별 · 생년월일 · 국적 · 키 · 치수 · 컵 · 데뷔 · 은퇴 · 별점 · 즐겨찾기 · 메모)를 UTF-8 `항목: 값` 형식으로 만듦. 같은 이름이 있으면 덮어쓰고 내용이 같으면 그대로 둠. 배우 txt 는 배우 폴더 텍스트 읽기 형식과 같아서 다시 읽어 들일 수 있음(다른이름은 읽을 때 뒤집히므로 거꾸로 기록), 영상 txt 는 첫 줄 `# RuliManager 영상 정보` 로 구분해 배우 정보로 읽지 않음
- **배우 폴더 텍스트 → 배우 정보**: 새 배우를 추가할 때, 그리고 배우 정보(생년월일·키·국적·데뷔·은퇴·치수·컵)가 모두 비어 있는 배우는 배우 폴더 바로 아래의 텍스트 파일(*.txt — 폴더/배우 이름 · profile · info · actor · 프로필 · 정보 이름 우선)에서 `항목: 값` 줄을 읽어 비어 있는 칸만 채움. 인식 항목(한국어·영어·일본어): 생년월일/생일/birthday/生年月日, 키/신장/height/身長, 치수/쓰리사이즈/measurements/スリーサイズ(B105 W59 H88 · 105-59-88 · B105(I)), 가슴/허리/엉덩이(bust/waist/hip), 컵/cup/カップ, 국적/출신/nationality/国籍(일본·Japan·日本·JP → 일본), 성별/gender, 데뷔/debut/デビュー, 은퇴/retire/引退, 별칭/다른이름/aka/別名(쉼표 · 、 · / · # 로 나눠 여러 개 → 파일에 적힌 순서의 반대로 별칭에 추가. 배우 이름과 같은 이름 — 전체 이름, 괄호 앞 이름, 괄호 안 각 이름(공백·대소문자 무시) — 과 이미 있는 별칭은 추가 안 함), 메모/memo/bio. 구분자는 `:` `：` `=` 탭, 날짜는 1998-02-17 · 1998.2.17 · 1998년 2월 17일 · 19980217, 인코딩은 UTF-8 · UTF-16 · ANSI(CP949) 자동
- **[재 스캔]** ([새로고침] 오른쪽): 새로고침과 같은 폴더 스캔 + 이미 DB 에 저장된 영상에도 폴더 구조를 다시 적용해 비어 있는 배우 · 스튜디오 · 발매일을 채움(값이 있는 칸은 그대로). 새로 찾은 배우는 배우 폴더의 사진 · 텍스트 정보까지 반영
- **폴더 구조 자동 인식** (등록 폴더 기준, 영상 파일은 각자 영상 폴더 안): `폴더\영상\영상.mp4` → 영상만 / `폴더\배우\영상\영상.mp4` → 배우 지정 / `폴더\스튜디오\배우\영상\영상.mp4` → 스튜디오 · 배우 지정 (더 깊으면 위 두 단계 폴더 사용, 등록 폴더 바로 아래 영상 파일은 영상만). 영상 파일 이름이나 영상 폴더 이름에 `[2024.05.01]` / `[20240501]` 이 있으면 발매일로 지정(파일 이름 우선). 찾은 배우·스튜디오는 각 목록에 자동 추가. 새 배우를 추가할 때, 그리고 이미 등록된 배우 중 사진이 없는(사진 파일이 없어진) 배우도(시작 · 스캔 · 새로고침 때, 배우 이름이나 별칭과 같은 폴더) 배우 폴더(`폴더\배우\`) 바로 아래에 이미지 파일이 있으면 배우 사진으로 지정(폴더/배우 이름 · folder · poster · profile · cover · actor 이름 우선, 없으면 이름 순 첫 번째, Image\actors 에 암호화 사본). 새로 찾은 임시 항목에만 적용되며, 이미 DB에 저장된 영상의 정보는 바꾸지 않음
- **창 크기 기억**: 메인 창의 마지막 위치 · 크기 · 최대화 상태를 종료할 때 저장하고 다음 실행 때 그대로 복원 (모니터 구성이 바뀌어 화면 밖이면 기본 위치)
- **창 크기 조절**: 모든 탭에서 창 크기를 바꾸면 오른쪽 상세 정보 폭은 고정(280 DLU)되고 왼쪽 격자만 늘어나거나 줄어듦
- **확대 (4단계)**: [태그] 버튼 바로 오른쪽(고정 위치)의 슬라이더 — 끌기/클릭/휠/←→ 로 카드와 이미지 크기를 1 · 1.3 · 1.65 · 2.1 배로. 탭(영상·배우·스튜디오·태그)마다 따로 기억
- **보기 전환 (상단 토글 버튼)**: [영상] [배우] [스튜디오] [태그] — 선택된 버튼은 파란색(#137CBD), 나머지는 #394B59. 영상 상세 정보(편집 칸)는 [영상] 탭에서만 표시하고, 다른 탭은 오른쪽에 이미지와 이름/정보 두 줄만 표시(이미지가 그만큼 커짐)
  - **배우**: 배우 카드 격자만 표시 — 세로 사진(오른쪽 아래 국기) · 성별 기호(♀ 분홍 / ♂ 파랑) + 이름(굵게) · 나이 · ▶ 출연 수. 검색창은 이름·별칭 검색. 배우를 선택하면 오른쪽에 사진과 정보, 더블클릭/Enter 하면 그 배우의 출연작 격자(오른쪽은 영상 탭과 같은 상세 정보 — 제목·별점·물방울·발매일·배우·스튜디오·태그 편집, fps/해상도, [이미지 검색/변경]. 태그 아래 배우 카드만 없음) → [◀ 배우 목록] 또는 Backspace 로 돌아가기. F2 / 오른쪽 클릭 → 배우 정보 편집, 오른쪽 클릭 → [배우 삭제] 또는 Del → 확인 후 배우 목록과 연결된 영상에서 삭제(영상 파일은 그대로, 옆 배우가 선택됨)
  - **스튜디오 / 태그**: 스튜디오(태그) 목록만 표시 (항상 격자: 스튜디오는 로고 카드 — 스튜디오 이미지(없으면 흰 카메라 아이콘) · 이름 · ▶ 영상 수 / 사람 아이콘 + 출연 배우 수, 태그는 흰 꼬리표 아이콘 · 이름 · ▶ 영상 수 카드, 태그는 이미지 없는 글자 카드, 검색창은 이름 검색). 태그 탭은 오른쪽 상세 페이지(이미지·정보) 없이 격자가 창 전체 폭을 씀. 항목을 선택하면 오른쪽에 이미지와 정보, 더블클릭/Enter 하면 해당 영상 격자 → [◀ 스튜디오 목록] 또는 Backspace 로 돌아가기. F2 / 오른쪽 클릭 → 편집
- **영상 격자 표시**: 영상은 카드로만 표시 — 가로 이미지(동영상과 같은 이름의 이미지 — movie.jpg / movie.mp4.jpg, 없으면 파일 이름의 '_' 왼쪽만 같은 이미지: ABC-123.mp4 ↔ ABC-123_cover.jpg, ABC-123_1080p.mp4 ↔ ABC-123.jpg, 여러 개면 이름 순 첫 번째. 비율을 유지한 채 이미지 전체가 보이도록 맞춤 — 자르지 않고 남는 곳은 여백) · 제목(굵게, 없으면 파일명) · 발매일(임시 항목은 "● 임시 (정보 저장 전)") · 제목(3줄, 메모 대신 · 글꼴 대체로 일본어 한자도 표시) · 꼬리표 아이콘 + 태그 수 / 사람 아이콘 + 배우 수. 스튜디오가 지정되어 있으면 이미지 오른쪽 위에 스튜디오 이미지(로고)를 반투명으로 표시(이미지가 없으면 스튜디오 이름). 상단 [정렬 ▾](이름·제목·크기·수정일·별점·발매일·배우·스튜디오·태그·경로) + [▲ 오름차순 / ▼ 내림차순]. 방향키/PgUp/PgDn/Home/End 이동, 더블클릭·Enter 재생, F2 이름 변경, Del 삭제, 오른쪽 클릭 메뉴. 이미지를 새로 넣었으면 [새로고침]. 카드 첫 줄 품번 오른쪽에 파일 순번 `(2/3)` — 파일 이름(확장자 제외)의 마지막 '_' 오른쪽이 숫자(4자리 이하)면 그 값이 순번, 분모는 같은 폴더에서 '_' 왼쪽 이름이 같은 파일 수(순번 없는 `ABC-123.mp4` 도 포함), 묶음이 2개 이상일 때만 회색으로 표시
- **검색/필터**: 이름·품번·제목·발매일·배우·스튜디오·태그 실시간 검색(공백 = AND), 별점 이상 필터

- **시리즈 (레이블 하위)**: 영상의 새 항목 `시리즈`(하나, library DB V 줄 16번째 칸). 영상 상세의 [시리즈] 칩 입력(`IDC_SERIES_CHIPS`, 지금은 화면에서 숨김 — 값만 보관, 품번 접두어로 자동 지정 · txt · 붙여넣기로 입력) — 후보는 지금 레이블의 시리즈 먼저, 다른 시리즈는 오른쪽에 레이블 이름. 다른 레이블의 시리즈를 고르면 레이블(과 그 상위 제작사)도 그쪽으로, 레이블을 바꾸면 다른 레이블 소속 시리즈는 비움. 레이블은 시리즈 목록을 가짐(L 줄 8번째 칸, 줄바꿈 구분 — 시리즈 하나는 레이블 하나에만). 저장 때 영상 시리즈가 어느 레이블에도 없으면 그 영상 레이블의 시리즈로 등록, 레이블이 비어 있으면 시리즈의 레이블로 채움. 영상 txt · 텍스트 입력 · 웹페이지 붙여넣기의 `시리즈/series/シリーズ` 항목, [정보 txt 생성]에도 기록, 상단 검색 포함. [제작사 / 레이블 관리] 창: 제작사 항목에는 [레이블] 칩(하위 레이블 여러 개 — 다른 레이블을 넣으면 이 제작사 아래로 옮김, 새 이름은 새 레이블, 칩에서 빼면 그 레이블은 상위 없음). 시리즈(품번) 표는 별도 [품번 관리] 창(`CSeriesDlg`, `IDD_SERIES` — 메인 창 [목록 관리 ▾] → [품번 관리...], 제작사 탭에서 고른 제작사 / 레이블 또는 지금 영상의 레이블(없으면 제작사)이 선택된 채 열림): 왼쪽 = 제작사 / 레이블 목록(관리 창과 같은 순서 — 제작사 아래 └ 레이블, 상위 없는 레이블은 맨 아래, 오른쪽 열 = 품번 수, 검색은 이름 · 서브이름 · 품번 · 라벨), 오른쪽 = 고른 항목의 시리즈 표(레이블 · 제작사 모두 — 제작사는 library DB S 줄 8번째 칸, 레이블은 L 줄 8번째 칸), 다른 항목을 고르면 표가 반영되고 [확인] = 저장, [취소] = 이 창에서 바꾼 것 모두 되돌림(확인 질문), 다른 항목에 있는 품번을 입력하면 옮길지 물음 — 열: 품번 | 라벨(별도 표기) | 설명 (시리즈 = 품번 접두어, 대문자로 저장 · 같은 품번 중복 불가 — 예전 "시리즈 이름 + 품번" 줄은 읽을 때 품번을 시리즈로), 셀 더블클릭 / F2 로 편집(Enter 저장 · Esc 취소 · Tab 다음 셀), 마지막 줄 "+ 새 품번"을 더블클릭하거나 오른쪽 클릭 → 추가, Delete / 오른쪽 클릭 → 삭제, 오른쪽 클릭 → [웹페이지 내용 붙여넣기 (일괄 추가)...] 또는 아래 [웹페이지 붙여넣기...] 버튼 — 사이트의 시리즈 · 품번 목록(표)을 복사해 붙여넣으면 줄마다 칸(탭, 없으면 두 칸 이상 공백 · " | " · " / " · " - ")으로 나눠 앞쪽 세 칸 중 품번 모양(영문 2자 이상, "SONE-479"/"SONE479" → SONE, "300MIUM-001" → 300MIUM)을 품번, 다음 칸을 라벨, 나머지를 설명으로 추가(이미 있는 품번은 빈 라벨 · 설명만 채움, 품번이 없는 줄은 건너뜀), 다른 레이블 · 제작사에 있던 같은 이름의 시리즈는 이 항목으로 옮김. 저장 형식은 한 줄에 하나 "이름␟품번␟라벨␟설명"(`SeriesInfo`, `ParseSeries` / `JoinSeries`, 예전 이름만 있는 값도 그대로 읽음). 영상 시리즈가 비어 있고 품번의 접두어("-" 앞)가 어떤 시리즈(품번)와 같으면 저장 · 스캔 때 그 시리즈(와 레이블 · 제작사)로 자동 지정 (`SeriesForCode`, "SONE-4" 처럼 "-" 포함 접두어는 앞부분 일치). 영상에서 제작사 소속 시리즈를 고르면 제작사가 그 제작사로(다른 제작사 레이블은 비움), 제작사를 바꾸면 다른 제작사 소속 시리즈는 비움, 저장 때 어디에도 없는 시리즈는 영상 레이블에(레이블이 없으면 제작사에) 등록
- **격자 빈곳 오른쪽 클릭 → 새 항목**: 배우 탭 [새 배우 추가...] (이름 입력 → 배우 관리 창), 제작사 탭 [새 제작사 추가...] / [새 레이블 추가...] (이름 입력 → 제작사 / 레이블 관리 창에서 이미지 · 상위 · 시리즈 입력, 제작사 · 레이블 이름 중복 불가), 태그 탭 [새 태그 추가...], 영상 격자 · 출연작 화면은 [폴더 추가...] / [새로고침] (`ShowNewItemMenu`)
- **스튜디오 입력**: 영상 상세의 스튜디오도 배우 · 태그와 같은 칩 입력 — [스튜디오 ×] 칩 + 입력 칸(자동 완성) + 오른쪽 ×(지우기) · ⌄(스튜디오 선택 창). 스튜디오는 하나만이라 새로 입력 · 선택하면 바뀜, 빈 입력 칸에서 Backspace 로 지움. 스튜디오 이미지가 있으면 칩의 스튜디오명 왼쪽에 이미지(칩 높이에 맞춰 비율 유지, 넓은 로고는 높이의 3배 폭까지, `CTagChipCtrl::m_iconWidth / m_drawIcon`). 값은 숨긴 스튜디오 칸에 보관 (`IDC_STUDIO_CHIPS`)
- **이미지 끌어다 놓기**: 영상 탭(또는 배우 출연작 화면)의 상세 이미지 영역에 탐색기의 이미지 파일을 끌어다 놓으면 [이미지 변경]과 같이 새 이미지로 미리보기 → [저장](또는 다른 항목 선택)하면 영상 파일 옆에 적용. 여러 개를 놓으면 첫 번째 파일, 이미지 영역 밖이나 이미지가 아닌 파일은 무시(열 수 없으면 알림). 관리자 권한으로 실행해도 받도록 메시지 필터 허용
- **분할 파일 (같은 정보 사용)**: 같은 폴더에서 파일 이름의 마지막 '_' 왼쪽이 같고 오른쪽이 숫자인 파일(`ABC-123_1.mp4`, `ABC-123_2.mp4`, 순번 없는 `ABC-123.mp4` 포함)은 한 묶음 — 카드는 파일 수만큼 표시(품번 오른쪽 `(1/3)`)하지만 품번 · 제목 · 별점 · 물방울 · 발매일 · 배우(참여 별칭) · 스튜디오 · 태그는 같이 사용. 한 파일에서 저장하면(별점 · 물방울 클릭 포함) 묶음 전체에 복사되고 임시 파일도 함께 등록. 시작할 때와 스캔으로 새 파일을 찾았을 때 묶음마다 빈 정보를 등록된 파일(이름 순 첫 파일 우선)의 값으로 채움(이미 들어 있는 값은 덮어쓰지 않음, 등록된 파일이 있으면 임시 파일도 등록). 이미지 변경은 순번을 뗀 이름(`ABC-123.jpg`)으로 저장하고 파일별 이미지(`ABC-123_2.jpg`)는 휴지통으로 → 묶음 전체가 같은 이미지. DB 형식은 그대로(파일마다 줄이 있고 값만 같게 유지)
- **품번**: 영상 상세 정보의 제목 위 [품번] 칸(폭 1/3 — 오른쪽에 품번 접두어가 제작사 · 레이블의 시리즈(품번)와 같으면 그 시리즈의 라벨명 표시, `SeriesInfoForCode`)(검색 대상, [이미지 검색] 기본 검색어). 비어 있으면 파일 이름 → 영상 폴더 이름에서 자동으로 찾음(영문 2~6자 + -/_/공백 + 숫자 2~5자 → `ABC-123` 대문자, 시작 · 스캔 · 재 스캔 때). 영상 txt 의 품번/code/品番 항목도 읽고, [정보 txt 생성]에도 기록 (library.tsv V 줄 14번째 칸)
- **출연 배우 카드**: 영상 상세 정보의 태그 아래에 이 영상의 배우를 작은 세로 카드(사진 3:4 · 별점 리본 · 즐겨찾기 하트 · 이름 / 괄호 안 이름 또는 나이)로 가로 한 줄 표시. 넘치면 휠 · 아래 스크롤바로 이동, 마우스를 올리면 전체 이름 툴팁, 더블클릭하면 배우 탭에서 그 배우 선택. 사진 오른쪽 아래 국기, 오른쪽 위 하트로 즐겨찾기 지정/해제(마우스를 하트 자리에 올리면 반투명 회색 하트, 클릭하면 바로 저장). 배우 칸을 바꾸면 바로 갱신 (`ActorStrip.h`)
- **제목·별점·발매일·배우·스튜디오·태그**: 오른쪽 아래 패널에서 편집. 상세보기의 글자 컨트롤(라벨 · 파일 이름 · 이미지 줄 · 품번 · 제목 · 발매일 · 배우/스튜디오/태그 칩)은 기본 글꼴보다 1pt 크게(줄 높이 · 라벨 폭도 맞춤, `ApplyDetailFonts`). 제목 칸은 여러 줄 에디트(자동 줄바꿈, 글꼴 4줄 높이, Enter = 저장, 붙여 넣은 줄바꿈은 공백으로 저장). 영상 메모 기능은 삭제(메모 칸 없음 → 그만큼 이미지가 커짐, 예전 메모는 읽지 않고 다음 저장 때 지워짐) (발매일은 체크를 해제하면 "없음"), 다른 항목 선택 시 자동 저장
- **파일 작업**: 이름 변경(F2 키만, 버튼·오른쪽 클릭 메뉴는 없음), [DB 삭제 (Del)] = 선택한 영상의 DB 정보만 삭제(파일은 유지, 저장된 영상은 임시 항목으로 돌아감 / 임시 항목은 목록에서 빠지고 다음 스캔 때 다시 나타남 / 파일이 없으면 목록에서 제거), 탐색기에서 보기, 기본 플레이어로 열기, 오른쪽 클릭 메뉴

## 데이터 저장 위치
DB 는 실행 파일 폴더의 `library.vmdb` (정보: 영상·배우·스튜디오·태그 + 임시 목록, 암호화) 하나와 `Image` 폴더(등록 이미지 파일 — `Image\actors` 배우 사진 / `Image\studios` 스튜디오 이미지, 태그는 이미지 없음). 이 파일과 폴더만 옮기면 다른 PC 에서도 그대로 동작 (실행 파일 폴더에 쓸 수 없으면(Program Files 등) `%APPDATA%\VideoManager`, 예전 위치 %APPDATA% 의 library.vmdb 는 처음 실행 때 실행 파일 폴더로 복사하고 .bak 으로 남김). 하단 [DB 폴더 열기] 버튼으로 탐색기에서 바로 열기
- **작업 DB (반영 방식)**: 실행하면 `library.vmdb` 를 `library.work.vmdb` 로 복사해서 사용하고, 실행 중 저장(별점·정보 저장·배우/태그 편집 등)은 작업 DB 에만 씀. 하단 [DB 반영] 버튼(반영 안 한 변경이 있을 때만 활성, 초록색) 또는 종료할 때 작업 DB 를 원본에 원자적으로 반영(임시 파일에 복사 후 교체)하고, 종료 시 작업 DB 삭제. 반영에 실패하면 종료할지 물어봄. 비정상 종료로 작업 DB 가 남아 있고 원본과 다르면 다음 실행 때 [예] 반영 / [아니요] 버리기 선택. 이미지는 Image 폴더에 바로 저장됨
- **시작 시 DB 백업**: 프로그램을 켤 때마다 불러오기 전에 `library.vmdb` 를 DB 폴더의 `backup` 폴더에 `library_YYYYMMDD_HHMMSS.vmdb` 형식으로 복사. 가장 최근 백업과 내용이 같으면 건너뛰고, 최근 10개만 남김(이미지는 Image 폴더에 파일로 있어서 백업하지 않음). 되돌리려면 프로그램을 끄고 백업 파일을 원래 이름으로 바꿔 DB 폴더에 덮어쓰기
- **등록 이미지 복사본**: 배우 사진 · 스튜디오 이미지를 등록하면 원본을 복사해서 실행 폴더의 `Image` 폴더(actors / studios)에 **암호화해서** 보관 — 파일 이름은 `날짜-시각_원래이름.jpg.vmimg`, 내용은 DB 와 같은 AES-256 암호화라 탐색기·이미지 뷰어로는 볼 수 없고 프로그램이 메모리에서만 풀어서 표시(평문 임시 파일 없음). 예전에 평문으로 저장된 Image 폴더 이미지는 시작할 때 암호화 사본으로 바꾸고 DB 저장 후 평문 파일 삭제 (태그는 이미지 없음, 예전 태그 이미지 기록은 무시) → 원본을 옮기거나 지워도 이미지 유지. DB 에는 Image 폴더 기준 상대 경로로 기록. 이미지 DB(images.vmdb)는 없앰 — 예전 images.vmdb 는 처음 실행 때 Image 폴더로 풀고 `images.vmdb.bak` 으로 남김
- 예전에 원본 경로로 등록된 이미지는 프로그램 시작 시 자동으로 복사본으로 교체(원본이 남아 있는 경우). 쓰이지 않게 된 복사본은 다음 시작 때 정리되고 다음 저장부터 DB 파일에서 빠짐

- 배우 카드: 성별 기호 + 이름(최대 2줄, 이름에 "(…)" 가 있으면 첫 줄 = 괄호 앞 이름(굵게, 영상 카드 제목보다 1pt 크게), 그 아래 = 괄호 안 이름(회색, 기본 글꼴보다 1pt 크게, 쉼표 , ， 、 로 나눠 줄마다 최대 2줄 - 더 있으면 둘째 줄에 이어서), 전각 （）도 인식) · 나이 · 출연 수 (별칭은 카드와 배우 상세에 표시하지 않음, 배우 관리 창 이름 콤보에서 확인)
- 이름의 쉼표: 쉼표는 목록 구분자지만 괄호 ( ) / （ ） 안의 쉼표는 이름의 일부로 허용 — 예: "나기 히카루(Hikaru Nagi, 凪ひかる)" 는 한 이름 (배우·별칭·스튜디오·태그 입력, 칩, 자동 완성, 폴더 스캔 공통)
- 배우 치수 / 컵: 배우 관리 창 [치수] B-W-H (cm, 숫자 칸 3개), [컵] (키 오른쪽, 미지정 / A~Q). 배우 탭 상세에 "치수: B95 W58 H88", "컵: I컵" 표시 (library.tsv A 줄 16~19번째 칸)
- 날짜 칸(생년월일 · 데뷔일 · 은퇴일 · 발매일) 직접 입력: 숫자로 "19980217" 을 치면 바로 확정, "1998-2-17" / "1998.2.17" 처럼 구분자를 넣으면 Enter 또는 다른 칸으로 이동할 때 확정 (잘못된 날짜는 원래 값 유지), Backspace 입력 중 지우기 · Esc 취소 · 입력 중이 아닐 때 Delete/Backspace 는 날짜 지우기, ▼ 달력도 그대로. 칸이 선택되면 날짜 글자 뒤를 회색 블록으로 칠해서 표시
- 영상 카드 제목: 카드 이름 글꼴보다 2pt 큰 굵은 글꼴 (카드 높이도 그만큼), 발매일 · 제목은 기본보다 1pt 큰 굵은 글꼴, 발매일과 제목 사이 2pt 간격
- 경로가 바뀐 파일 다시 연결: 영상 파일을 다른 폴더로 옮기거나 이름을 바꿔도, 프로그램 시작 시(없어진 항목이 있을 때만 스캔) · 새로고침(F5) · 폴더 추가 때 기존 DB 항목의 경로만 고쳐서 제목·별점·배우·태그·메모 등 정보를 유지. 같은 파일 기준 = 크기가 같고 파일 이름 또는 수정 시각이 같음. 새로고침 때 등록 폴더 자체에 접근할 수 없으면(외장 드라이브 분리 등) 그 아래 항목은 지우지 않음
- DB 파일 형식/암호화: library.vmdb = "VMDB-PACK1" + [정보 묶음] + [길이 0], 정보 묶음은 AES-256-CBC(Windows CNG) 암호화 (키 = 프로그램 안 고정 문자열의 SHA-256, `DbCrypt.h`). 이미지까지 한 파일에 들어 있던 예전 library.vmdb 나 예전 images.vmdb("VMDB-IMGS1") 의 이미지는 처음 실행 때 Image 폴더로 풀어 냄. 예전 형식(library.tsv / pending.tsv / images 폴더)은 처음 실행 때 읽어서 묶고 .bak 으로 남겨 둠. 복호화에 실패하면 경고하고 그 실행에서는 저장하지 않아 기존 DB 를 덮어쓰지 않음. 메모장으로 못 보게 하는 수준(프로그램을 분석하면 풀 수 있음), 키 문자열을 바꾸면 기존 DB 를 못 읽음
- 배우 사진 검색: 배우 관리 창 [사진 검색...] (사진 선택 버튼 아래) → 배우 풀 네임(괄호 안 영문/일본어 이름 포함, 검색 창에서 고칠 수 있음)으로 API 키 없이 이미지 검색. 검색 엔진 콤보 Bing / Yandex, [세이프서치 끄기] 체크 (둘 다 기억), 썸네일 10개(5×2, 각 칸 아래 원본 크기 · 확장자 "1280×720 · JPG", 크기를 모르면 확장자만)씩 [◀ 이전] [다음 10개 ▶] 로 넘겨 보기 (다음 결과는 필요할 때 더 받음). 클릭 후 [선택] 또는 더블클릭 → 원본을 받아(실패하면 썸네일) DB 폴더 images\actors 에 복사해서 사진으로 지정. 검색 결과 페이지를 읽는 비공식 방식이라 엔진 페이지가 바뀌면 해당 Fetch 함수를 고쳐야 할 수 있음 (`ImageSearchDlg.h`, `WebHelper.h`, WinHTTP)
- 영상 이미지 변경: 영상 탭 상세의 이미지 줄 오른쪽 [이미지 검색...] (배우 사진 검색과 같은 창, 검색어 = 제목 또는 파일 이름에서 [날짜] 등 대괄호 부분 제외) 또는 [이미지 변경...] (파일 선택) → 고른 이미지는 미리보기에 바로 표시, [저장](또는 다른 영상으로 이동해 자동 저장)하면 영상 파일과 같은 폴더에 "영상이름.확장자"(예: movie.mp4 → movie.png)로 복사. 같은 이름의 기존 이미지(다른 확장자, movie.mp4.jpg 형식 포함)는 휴지통으로 보내서 새 이미지가 쓰이게 함
