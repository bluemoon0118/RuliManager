# RuliManager v0.1 (MFC, Visual Studio 2022)

- 버전: 0.1 — 창 제목 "RuliManager v0.1", 파일 버전 정보 0.1 (`RuliManager.rc` 의 CAPTION 과 VERSIONINFO 에서 변경)

## 빌드
1. Visual Studio Installer에서 **"C++를 사용한 데스크톱 개발"** + **"최신 v143 빌드 도구용 C++ MFC"** 구성 요소 설치
2. `RuliManager.sln` 열기 → 구성 `Debug|x64` 또는 `Release|x64` → 빌드(Ctrl+Shift+B) → 실행(F5) — 실행 파일 이름은 `RuliManager.exe` (폴더 `D:\Project\RuliManager`, 예전 이름 VideoManager 에서 바꿈. 기존 데이터를 그대로 쓰도록 내부 저장 이름 — 설정 레지스트리 키 · %APPDATA%/%LOCALAPPDATA% 폴더 · DB 암호화 키 — 는 VideoManager 그대로)

## 기능
- **폴더 추가/제거/새로고침**: 하위 폴더까지 동영상 검색 (mp4, mkv, avi, wmv, mov, webm, ts 등). 새로 찾은 파일은 **임시 목록**(`pending.tsv`)에 기록되고 격자에 "● 임시"로 표시 → 영상 정보를 저장([저장] 또는 정보 수정 후 다른 영상 선택)하면 정식 DB(`library.tsv`)에 등록
  - **폴더 구조 자동 인식** (등록 폴더 기준, 영상 파일은 각자 영상 폴더 안): `폴더\영상\영상.mp4` → 영상만 / `폴더\배우\영상\영상.mp4` → 배우 지정 / `폴더\스튜디오\배우\영상\영상.mp4` → 스튜디오 · 배우 지정 (더 깊으면 위 두 단계 폴더 사용, 등록 폴더 바로 아래 영상 파일은 영상만). 영상 파일 이름이나 영상 폴더 이름에 `[2024.05.01]` / `[20240501]` 이 있으면 발매일로 지정(파일 이름 우선). 찾은 배우·스튜디오는 각 목록에 자동 추가. 새로 찾은 임시 항목에만 적용되며, 이미 DB에 저장된 영상의 정보는 바꾸지 않음
- **창 크기 기억**: 메인 창의 마지막 위치 · 크기 · 최대화 상태를 종료할 때 저장하고 다음 실행 때 그대로 복원 (모니터 구성이 바뀌어 화면 밖이면 기본 위치)
- **창 크기 조절**: 모든 탭에서 창 크기를 바꾸면 오른쪽 상세 정보 폭은 고정(280 DLU)되고 왼쪽 격자만 늘어나거나 줄어듦
- **확대 (4단계)**: [태그] 버튼 바로 오른쪽(고정 위치)의 슬라이더 — 끌기/클릭/휠/←→ 로 카드와 이미지 크기를 1 · 1.3 · 1.65 · 2.1 배로. 탭(영상·배우·스튜디오·태그)마다 따로 기억
- **보기 전환 (상단 토글 버튼)**: [영상] [배우] [스튜디오] [태그] — 선택된 버튼은 파란색(#137CBD), 나머지는 #394B59. 영상 상세 정보(편집 칸)는 [영상] 탭에서만 표시하고, 다른 탭은 오른쪽에 이미지와 이름/정보 두 줄만 표시(이미지가 그만큼 커짐)
  - **배우**: 배우 카드 격자만 표시 — 세로 사진(오른쪽 아래 국기) · 성별 기호(♀ 분홍 / ♂ 파랑) + 이름(굵게) · 나이 · ▶ 출연 수. 검색창은 이름·별칭 검색. 배우를 선택하면 오른쪽에 사진과 정보, 더블클릭/Enter 하면 그 배우의 출연작 격자(오른쪽은 영상 탭과 같은 상세 정보 — 제목·별점·물방울·발매일·배우·스튜디오·태그·메모 편집, fps/해상도, [이미지 검색/변경]. 메모 아래 배우 카드만 없음) → [◀ 배우 목록] 또는 Backspace 로 돌아가기. F2 / 오른쪽 클릭 → 배우 정보 편집
  - **스튜디오 / 태그**: 스튜디오(태그) 목록만 표시 (항상 격자: 스튜디오는 로고 카드 — 스튜디오 이미지(없으면 흰 카메라 아이콘) · 이름 · ▶ 영상 수 / 사람 아이콘 + 출연 배우 수, 태그는 흰 꼬리표 아이콘 · 이름 · ▶ 영상 수 카드, 태그는 이미지 없는 글자 카드, 검색창은 이름 검색). 태그 탭은 오른쪽 상세 페이지(이미지·정보) 없이 격자가 창 전체 폭을 씀. 항목을 선택하면 오른쪽에 이미지와 정보, 더블클릭/Enter 하면 해당 영상 격자 → [◀ 스튜디오 목록] 또는 Backspace 로 돌아가기. F2 / 오른쪽 클릭 → 편집
- **영상 격자 표시**: 영상은 카드로만 표시 — 가로 이미지(동영상과 같은 이름의 이미지 — movie.jpg / movie.mp4.jpg, 없으면 파일 이름의 '_' 왼쪽만 같은 이미지: ABC-123.mp4 ↔ ABC-123_cover.jpg, ABC-123_1080p.mp4 ↔ ABC-123.jpg, 여러 개면 이름 순 첫 번째. 카드 폭에 맞춰 자름) · 제목(굵게, 없으면 파일명) · 발매일(임시 항목은 "● 임시 (정보 저장 전)") · 메모(3줄) · 꼬리표 아이콘 + 태그 수 / 사람 아이콘 + 배우 수. 스튜디오가 지정되어 있으면 이미지 오른쪽 위에 스튜디오 이미지(로고)를 반투명으로 표시(이미지가 없으면 스튜디오 이름). 상단 [정렬 ▾](이름·제목·크기·수정일·별점·발매일·배우·스튜디오·태그·경로) + [▲ 오름차순 / ▼ 내림차순]. 방향키/PgUp/PgDn/Home/End 이동, 더블클릭·Enter 재생, F2 이름 변경, Del 삭제, 오른쪽 클릭 메뉴. 이미지를 새로 넣었으면 [새로고침]
- **검색/필터**: 이름·제목·발매일·배우·스튜디오·태그·메모 실시간 검색(공백 = AND), 별점 이상 필터
- **재생**: 더블클릭 / Enter / Space → 기본 플레이어(파일 연결 프로그램)로 열기
- **미리보기 이미지**: 동영상과 같은 이름의 이미지(`movie.jpg` 또는 `movie.mp4.jpg`, jpg/jpeg/png/webp/bmp/gif/tif)를 오른쪽 위에 표시. 동영상 이름을 바꾸면 이미지도 함께 바뀜
- **배우 관리**: [목록 관리 ▾] → 배우 관리(또는 배우 보기에서 배우 더블클릭)으로 별도 창을 열어 배우 추가·수정·삭제. 왼쪽 목록에 이름·성별·나이·생년월일·국적(국기)·키·데뷔일·은퇴일·출연 수·별칭을 모두 표시(창을 넓혔고, 창 크기를 조절하면 목록이 함께 넓어짐). 배우별 사진·성별(여성/남성)·생년월일(만 나이 자동 표시)·별칭(콤보박스: ▾ 로 펼침 목록, 마지막으로 고른 별칭 기억, 새 별칭 입력 후 Enter 로 추가. 펼침 목록 오른쪽 스핀 버튼(▲▼, 또는 Ctrl+↑/↓)으로 순서 변경, 더블클릭/Enter 로 선택, 우클릭 → [삭제] 메뉴 또는 Del 로 삭제. 별칭 입력 칸을 더블클릭하면 글자 전체 선택)·은퇴일·국적(콤보박스: [국기] 나라 이름, 63개국 — 국기는 `res\flags.bmp`, 배우 관리 목록의 국적 칸에도 국기 표시)·키·데뷔일·별칭(여러 개, 쉼표 구분)·메모·출연작 수. 별칭으로도 배우/영상 검색. **영상의 배우가 별칭으로 적혀 있어도 해당 배우에 연결**(출연작 수·출연작 보기·배우 선택 체크·삭제 모두 반영, 새 배우를 따로 만들지 않음). 별칭을 입력했는데 같은 이름의 배우가 따로 등록되어 있으면 합칠지 물어봄. 이름을 바꾸면 연결된 동영상에도 반영, 삭제하면 동영상에서도 빠짐
- **스튜디오 / 태그 관리**: [목록 관리 ▾] → 스튜디오 관리 / 태그 관리 (또는 스튜디오·태그 목록에서 F2 / 오른쪽 클릭 → 편집). 이름·이미지(스튜디오만)·메모(스튜디오만, 태그는 메모 없음)·영상 수. 이름을 바꾸면 동영상에도 반영, 삭제하면 동영상에서도 빠짐
- **일괄 등록**: 태그(스튜디오) 관리 창의 [일괄 등록] → 한 줄에 하나씩 또는 쉼표로 여러 이름 입력(엑셀에서 붙여넣은 탭도 구분자, 괄호 안 쉼표는 이름의 일부). 오른쪽 미리보기에 신규(초록) / 이미 있음(회색) / 입력 중복(주황) 표시, [즐겨찾기로 등록] 체크 가능, [등록 (N)] 으로 신규만 추가 (`BulkNameDlg.h`)
- **동영상의 스튜디오 / 태그 지정**: 상세 정보의 [선택...] → 목록에서 체크 (스튜디오는 하나, 태그는 여러 개, 목록에 없으면 바로 추가)
- **동영상의 배우 지정**: 배우 칩의 ⌄ → 배우 선택 창에서 체크 (목록에는 대표 이름만 표시, 별칭으로도 검색됨, 목록에 없으면 바로 추가)
- **이름 = 대표 이름 + 별칭**: 배우 관리 창의 [이름] 콤보에 대표 이름과 별칭이 모두 들어 있고, 마지막으로 고른 이름이 대표 이름(배우 카드·목록·영상에 표시되는 이름)이 됨. 새 이름은 입력 후 Enter, 삭제는 펼침 목록 우클릭, 순서는 스핀
- **설정**: 메인 창 오른쪽 위 톱니바퀴 버튼 → 설정 창 (`SettingsDlg.h`). [DB 삭제] 영상 / 배우 / 스튜디오 / 태그 체크(개수 표시) 후 [선택한 DB 삭제] → 확인 후 즉시 삭제·저장 (영상: 저장 정보 + 임시 항목 모두, 다시 스캔하면 임시로 다시 나타남 / 배우·스튜디오·태그: 목록과 영상에 지정된 값 함께 / 영상 파일·이미지 원본은 지우지 않음, 쓰이지 않는 이미지 복사본은 다음 시작 때 정리)
- **별점**: 상세 정보의 별점은 별 다섯 개 `★★★★☆ 4` 로 표시 — 마우스를 올린 위치까지 별이 미리 보이고, 클릭하면 별점이 확정되어 바로 저장 (같은 별을 다시 클릭하거나 [별점] 라벨을 클릭하면 0점으로 리셋), ←→ / 숫자 키 / 휠로도 변경 (`StarRatingCtrl.h`). 영상 탭 카드에도 배우 카드와 같은 대각선 리본 "별점: N" (같은 별점별 색) 을 이미지 왼쪽 위에 표시
- **배우 상세(배우 탭 오른쪽 아래)**: 사진 아래에 큰 굵은 이름 + ♥(즐겨찾기), 그 아래 ☆☆☆☆☆ 별점(클릭하면 바로 저장), 그리고 회색 라벨 / 흰 값 줄로 성별 · 나이 "28 (1998-02-17)" · 국적 "일본 [국기]" · 키 "162cm" · 데뷔 · 은퇴 · 출연 (값이 있는 것만). 맨 아래에 별칭 변경 이력 "아스카 아카 → 시오세 → 나기 히카루" (배우 관리 창 이름 콤보 순서의 역순 = … 별칭2 → 별칭1 → 대표 이름, 괄호 부분은 빼고, 산호색 굵게, 넘치면 줄바꿈 · 괄호를 뺀 서로 다른 이름이 2개 이상일 때만 표시(같은 이름은 하나로) · 순서는 배우 관리 창 이름 콤보의 ▲▼ 로 바꿈), 그 아래 메모 (여러 줄, 최대 8줄 · 넘치면 …) (`ActorDetailPanel.h`)
- **태그 즐겨찾기**: 태그 탭 카드 오른쪽 위 하트 — 배우 카드와 같게 즐겨찾기면 빨간 하트, 하트 자리에 마우스를 올리면 반투명 회색 하트, 클릭하면 지정/해제(바로 저장, 태그 목록에 없던 태그는 목록에 추가). 즐겨찾기한 태그가 먼저 나옴 (library.tsv T 줄 5번째 칸)
- **배우 즐겨찾기**: 배우 탭 카드 오른쪽 위 하트 — 즐겨찾기면 빨간 하트, 하트 자리에 마우스를 올렸을 때만 반투명 회색 하트가 보이고 하트를 클릭하면 즐겨찾기 지정/해제(바로 저장). 배우 탭은 즐겨찾기한 배우가 먼저(그 안에서 이름 순) 나오고 지정/해제하면 바로 다시 정렬. 오른쪽 패널의 "배우: 이름 (만 N세)" 바로 오른쪽 하트로도 지정/해제 (카드와 같은 색: 즐겨찾기 빨강 #F25C54, 아니면 회색, 마우스 오버 시 밝은 회색) (`HeartToggle.h`) (library.tsv A 줄 15번째 칸)
- **배우 별점**: 배우 관리 창의 [별점] 칸(은퇴일 아래)에서 영상과 같은 별 다섯 개로 지정 — 마우스 오버 미리 보기, 클릭 확정 후 [저장]. 배우 탭 오른쪽 패널(사진 아래 정보 줄 밑)의 [별점] 에서도 바로 지정 가능(클릭하면 즉시 저장, 카드 리본 갱신). 배우 목록에 별점 열, 배우 탭 카드는 사진 왼쪽 위 모서리에 대각선 리본 "별점: N" 으로 표시(0점이면 없음, 띠 색: 1점 #394B59 · 2점 #63411E · 3점 #A66321 · 4점 #A82A2A · 5점 #FF2F39) (library.tsv A 줄 14번째 칸)
- **배우 칩**: 상세 정보의 배우도 태그처럼 칩 `[이름 ×]` 로 표시 — [별칭] 줄을 합쳐서 칩에는 이 작품에서 고른 별칭(없으면 대표 이름) 하나만 표시, 칩을 클릭하면 그 배우의 별칭 중에서 고름(고른 값이 이 작품의 별칭, 체크된 별칭을 다시 고르면 해제). 마지막으로 고른 별칭은 배우마다 기억해서, 다른 영상에 그 배우를 새로 넣으면(칩 입력·배우 선택 창) 그 별칭이 초기값으로 들어감, × 삭제 / 오른쪽 × 모두 지우기 / ⌄ 배우 선택 창. 입력 칸에 글자를 넣으면 배우 이름·별칭 자동 완성(↓ 전체), Enter / 쉼표 / 목록 선택으로 추가 (별칭으로 고르면 저장 시 배우 이름 + 참여 별칭으로 정리)
- **태그 칩**: 상세 정보의 태그는 칩 형태 `[태그 ×] [태그 ×] … ×  ⌄` 로 표시 — 칩의 × 로 삭제, 오른쪽 × 는 모두 지우기, ⌄ 는 태그 목록에서 선택. 칩 뒤 입력 칸에 글자를 넣으면 태그 목록에서 자동 완성(↓ 전체 목록), Enter / 쉼표 / 목록 선택으로 추가, 빈 칸에서 Backspace 는 마지막 태그 삭제. 칩이 넘치면 여러 줄로 늘어남
- **자동 완성 입력**: 상세 정보의 배우 · 별칭 · 스튜디오 · 태그 칸에 글자를 입력하면 DB(배우·별칭·스튜디오·태그 목록)에서 실시간으로 찾아 콤보박스처럼 아래에 목록 표시 → 마우스 클릭 또는 ↑/↓ + Enter(Tab)로 선택, Esc 닫기, 빈 칸에서 ↓ 는 전체 목록. 배우·별칭·태그는 쉼표로 여러 개(커서가 있는 값만 완성, 이미 입력한 값은 제외). 배우 칸에서 별칭을 고르면 저장 시 배우 이름 + 참여 별칭으로 정리, 별칭 칸에서 다른 배우의 별칭을 고르면 그 배우가 배우 칸에도 추가됨. 목록에 없는 값을 직접 입력해 저장하면 각 목록에 새로 추가
- **참여 별칭**: 상세 정보의 배우 아래 [별칭] — 이 작품에서 배우가 쓴 별칭. [선택...] → 지정된 배우들의 별칭 메뉴에서 체크/해제. 배우 칸에 별칭으로 적힌 배우(폴더 스캔 등)는 자동으로 본래 배우 이름 + 참여 별칭으로 정리되고, 배우를 빼면 그 배우의 참여 별칭도 함께 빠짐. 검색에도 포함
- **물방울 카운트**: 영상 상세 정보의 별점 오른쪽 `💧 0` — 클릭할 때마다 1 증가, 오른쪽 클릭 → [초기화] 로 0. 1 이상이면 영상 카드 아래 개수 줄(태그 수 · 배우 수 옆)에도 물방울 + 숫자 표시. 별점처럼 바로 저장 (library.tsv V 줄 13번째 칸, `DropCounter.h`, 아이콘 `VectorIcon::Drops`)
- **fps / 해상도**: 영상 상세 정보의 파일 이름 줄 오른쪽([이미지 검색][이미지 변경] 버튼 위)에 `fps: 29.97 | 1080p` 표시 (fps 회색, 해상도 흰색 굵게). 값은 Windows 파일 속성(프레임 속도 · 프레임 너비/높이)에서 읽고 경로별로 기억. 해상도는 16:9 기준 높이로 1080p · 2160p 등 표준 이름 (`MediaInfoLabel.h`). Windows 가 속성을 읽지 못하는 형식(코덱/속성 처리기 없음)은 표시 안 함
- **출연 배우 카드**: 영상 상세 정보의 메모 아래에 이 영상의 배우를 작은 세로 카드(사진 3:4 · 별점 리본 · 즐겨찾기 하트 · 이름 / 괄호 안 이름 또는 나이)로 가로 한 줄 표시. 넘치면 휠 · 아래 스크롤바로 이동, 마우스를 올리면 전체 이름 툴팁, 더블클릭하면 배우 탭에서 그 배우 선택. 사진 오른쪽 아래 국기, 오른쪽 위 하트로 즐겨찾기 지정/해제(마우스를 하트 자리에 올리면 반투명 회색 하트, 클릭하면 바로 저장). 배우 칸을 바꾸면 바로 갱신 (`ActorStrip.h`)
- **제목·별점·발매일·배우·스튜디오·태그·메모**: 오른쪽 아래 패널에서 편집 (발매일은 체크를 해제하면 "없음"), 다른 항목 선택 시 자동 저장
- **파일 작업**: 이름 변경(F2 키만, 버튼·오른쪽 클릭 메뉴는 없음), [DB 삭제 (Del)] = 선택한 영상의 DB 정보만 삭제(파일은 유지, 저장된 영상은 임시 항목으로 돌아감 / 임시 항목은 목록에서 빠지고 다음 스캔 때 다시 나타남 / 파일이 없으면 목록에서 제거), 탐색기에서 보기, 기본 플레이어로 열기, 오른쪽 클릭 메뉴

## 데이터 저장 위치
DB 는 실행 파일 폴더의 두 파일 — `library.vmdb` (정보: 영상·배우·스튜디오·태그 + 임시 목록) 와 `images.vmdb` (등록 이미지 복사본 묶음), 둘 다 암호화. 두 파일만 옮기면 다른 PC 에서도 그대로 동작 (실행 파일 폴더에 쓸 수 없으면(Program Files 등) `%APPDATA%\VideoManager`, 예전 위치 %APPDATA% 의 library.vmdb 는 처음 실행 때 실행 파일 폴더로 복사하고 .bak 으로 남김). 하단 [DB 폴더 열기] 버튼으로 탐색기에서 바로 열기
- **시작 시 DB 백업**: 프로그램을 켤 때마다 불러오기 전에 `library.vmdb` / `images.vmdb` 를 DB 폴더의 `backup` 폴더에 `library_YYYYMMDD_HHMMSS.vmdb` 형식으로 복사. 가장 최근 백업과 내용이 같으면 건너뛰고, 파일마다 최근 10개만 남김. 되돌리려면 프로그램을 끄고 백업 파일을 원래 이름으로 바꿔 DB 폴더에 덮어쓰기
- **등록 이미지 복사본**: 배우 사진 · 스튜디오/태그 이미지를 등록하면 원본을 복사해서 DB 파일 안에 보관 → 원본을 옮기거나 지워도 이미지 유지. 실행 중에는 `%LOCALAPPDATA%\VideoManager\cache\images` 에 풀어서 쓰고 종료할 때 지움
- 예전에 원본 경로로 등록된 이미지는 프로그램 시작 시 자동으로 복사본으로 교체(원본이 남아 있는 경우). 쓰이지 않게 된 복사본은 다음 시작 때 정리되고 다음 저장부터 DB 파일에서 빠짐

- 영상 카드 제목: 카드 이름 글꼴보다 2pt 큰 굵은 글꼴 (카드 높이도 그만큼), 발매일 · 메모는 기본보다 1pt 큰 굵은 글꼴, 발매일과 메모 사이 2pt 간격
- 경로가 바뀐 파일 다시 연결: 영상 파일을 다른 폴더로 옮기거나 이름을 바꿔도, 프로그램 시작 시(없어진 항목이 있을 때만 스캔) · 새로고침(F5) · 폴더 추가 때 기존 DB 항목의 경로만 고쳐서 제목·별점·배우·태그·메모 등 정보를 유지. 같은 파일 기준 = 크기가 같고 파일 이름 또는 수정 시각이 같음. 새로고침 때 등록 폴더 자체에 접근할 수 없으면(외장 드라이브 분리 등) 그 아래 항목은 지우지 않음
- DB 파일 형식/암호화: library.vmdb = "VMDB-PACK1" + [정보 묶음] + [길이 0], images.vmdb = "VMDB-IMGS1" + [이미지 묶음], 각 묶음은 AES-256-CBC(Windows CNG) 암호화 (키 = 프로그램 안 고정 문자열의 SHA-256, `DbCrypt.h`). 정보만 바뀌면 작은 library.vmdb 만 다시 쓰고, images.vmdb 는 이미지가 바뀌었을 때만 다시 씀. 이미지까지 한 파일에 들어 있던 예전 library.vmdb 는 처음 실행 때 두 파일로 나눔. 예전 형식(library.tsv / pending.tsv / images 폴더)은 처음 실행 때 읽어서 묶고 .bak 으로 남겨 둠. 복호화에 실패하면 경고하고 그 실행에서는 저장하지 않아 기존 DB 를 덮어쓰지 않음. 메모장으로 못 보게 하는 수준(프로그램을 분석하면 풀 수 있음), 키 문자열을 바꾸면 기존 DB 를 못 읽음
- 배우 사진 검색: 배우 관리 창 [사진 검색...] (사진 선택 버튼 아래) → 배우 풀 네임(괄호 안 영문/일본어 이름 포함, 검색 창에서 고칠 수 있음)으로 API 키 없이 이미지 검색. 검색 엔진 콤보 Bing / Yandex, [세이프서치 끄기] 체크 (둘 다 기억), 썸네일 10개(5×2, 각 칸 아래 원본 크기 · 확장자 "1280×720 · JPG", 크기를 모르면 확장자만)씩 [◀ 이전] [다음 10개 ▶] 로 넘겨 보기 (다음 결과는 필요할 때 더 받음). 클릭 후 [선택] 또는 더블클릭 → 원본을 받아(실패하면 썸네일) DB 폴더 images\actors 에 복사해서 사진으로 지정. 검색 결과 페이지를 읽는 비공식 방식이라 엔진 페이지가 바뀌면 해당 Fetch 함수를 고쳐야 할 수 있음 (`ImageSearchDlg.h`, `WebHelper.h`, WinHTTP)
- 영상 이미지 변경: 영상 탭 상세의 이미지 줄 오른쪽 [이미지 검색...] (배우 사진 검색과 같은 창, 검색어 = 제목 또는 파일 이름에서 [날짜] 등 대괄호 부분 제외) 또는 [이미지 변경...] (파일 선택) → 고른 이미지는 미리보기에 바로 표시, [저장](또는 다른 영상으로 이동해 자동 저장)하면 영상 파일과 같은 폴더에 "영상이름.확장자"(예: movie.mp4 → movie.png)로 복사. 같은 이름의 기존 이미지(다른 확장자, movie.mp4.jpg 형식 포함)는 휴지통으로 보내서 새 이미지가 쓰이게 함
